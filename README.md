# FareLock

Set your price. Cathay books it.

FareLock lets a traveller tell the airline the most they're willing to pay for a flight. It watches the fare and books the ticket automatically if the fare drops to that amount, so the airline fills seats that would otherwise fly empty without cutting fares for everyone.

Live demo: https://barnical66.github.io/farelock/

Student concept built for Cathay Hackathon 2026. Not affiliated with or endorsed by Cathay Pacific or the Cathay Group. Fares, flights and Asia Miles in the demo are illustrative.
